# Icon

Mit diesem Tag kann ein SVG-Icon erstellt werden.
Hier können alle Icons durchsucht werden: https://fontawesome.com/icons/packs/classic


        <!-- Usage Example -->

        Aufruf ohne Styling
        <x-bvvblades-icon name="user" type="solid"/>

        Aufruf mit Styling über Klassen und/oder Styles
        <x-bvvblades-icon name="user" type="solid" class="w-5 h-5 border" style="color: red"/>
        <x-bvvblades-icon name="user" type="regular" class="w-8 h-8 text-blue-500"/>


## Attribute

| Name  | Type    | mögliche Werte      |          | Beschreibung                                 |
| ----- | ------- | ------------------- | -------- | -------------------------------------------- |
| name  | string  |                     | Pflicht  | Name des Icons                               |
| type  | string  | solid, regular      | optional | Art des Icons (ausgefüllt )                  |
